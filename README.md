# AWS Learning ☁️

A personal repository documenting my learning journey with **Amazon Web Services (AWS)**.

The goal is to organize what I learn about AWS services, concepts, and best practices, while building a reference that can also be useful to other developers learning cloud computing.

## 📚 About This Repository

This repository contains notes, explanations, and examples from my AWS studies.

The content is organized by service and will be updated as I learn and practice new concepts.

## 🚀 Services Covered

### Amazon S3

**Amazon Simple Storage Service (S3)** is an object storage service used to store and retrieve data.

**Topics covered:**

* S3 fundamentals
* Buckets and objects
* Storage classes
* Lifecycle
* Versioning
* Access control
* Permissions
* Common use cases

### Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** provides virtual servers in the AWS cloud.

**Topics covered:**

* EC2 fundamentals
* Instances
* AMIs
* Instance types
* Key pairs
* Security groups
* Storage
* Basic use cases
